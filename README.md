# Project 2: Interactive Stopwatch Web App

## 📝 Description
This is a functional Stopwatch web application built to demonstrate proficiency in JavaScript timing events and CSS layout design. Users can start, stop, and reset the timer with a clean, responsive interface.

## 🚀 Features
- **Precise Timing:** Accurate start, pause, and reset functionality.
- **Lap Recording:** (Optional - add this if your script supports it) Ability to record time intervals.
- **Responsive UI:** Works seamlessly on both mobile and desktop browsers.

## 🛠️ Tech Stack
- **HTML5:** Semantic structure for the timer display and controls.
- **CSS3:** Custom styling for a modern, digital clock appearance.
- **JavaScript (Vanilla):** Logic for `setInterval`, `clearInterval`, and DOM manipulation.

## 📁 File Structure
- `index.html` - The main UI structure.
- `style3.css` - Stylesheet for the timer buttons and layout.
- `script1.js` - JavaScript logic for the stopwatch functionality.

## 🔧 How to Use
1. Clone this repository.
2. Open `index.html` in any web browser.
3. Use the 'Start' button to begin the timer, 'Stop' to pause, and 'Reset' to clear the time.
